How your data is stored

Everything you type stays on this device, in this browser. Nothing is uploaded. There is no account and no monthly fee.

If you switch browsers or sit down at a different computer, your lists will not be there. Use Backup / Restore all data regularly, and keep that file somewhere you can find it. Use the same browser and the same computer when you come back.

These pages work after they have loaded, even if the internet drops. Do not type Social Security numbers or bank account numbers in any box.

A shared computer: back up first, then clear the tool before the next person uses it.
